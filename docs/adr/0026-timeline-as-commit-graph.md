# ADR-0026: Timeline を、月を本線・出来事を分岐とするコミットグラフとして描く

Date: 2026-10-21
Status: Accepted

## Context

Timeline のデータは、月ごとの contributions 数（毎月 1 件）と、個々の出来事（リポジトリの公開、
OSS への貢献、記事）が混ざる（ADR-0025）。出来事は少なく、月の統計は毎月増える。
新しい順の 1 本のリストにすると、Home のダイジェストの大半を統計が占める。

サイトは chrome に VT323 を使い、ターミナルの要素を持つ（ADR-0019）。

## Decision

### 構造: 本線 = 月、分岐 = その月の出来事

- 本線は月ごとのノードを実線でつなぐ。ノードに月名と contributions 数を出す
- その月に出来事があれば、月のノードから分岐が出て、出来事のノードが縦に並ぶ
- 統計は個別のエントリではなく背骨になり、継続していることが線の連なりで伝わる
- 統計のない月（今月など）も、出来事があればノードを置く。件数は出さない

### 線とノード

| | 本線 | 分岐 |
| --- | --- | --- |
| 線 | 実線 3px、`--color-graph-mark` | 点線 2px、`--color-text-muted` |
| ノード | 輪 14px・太さ 3px、線と同じ色 | 本線と同じ形、線と同じ色 |

- 色で主従を示す。紫は背骨（と種類のタグ）、グレーは枝。分岐を本線と同色にすると、違いが線種だけになる
- ノードの色を線と変えない。分岐のノードだけ紫にすると、本線のノードと区別がつかない
- ノードは中を背景色で塗った輪にし、線がノードの裏を通って見えるようにする
- 分岐は月のノードの縁から 45° の放射方向に出て、真上から出来事のノードに入る 1 本の SVG の曲線にする。
  CSS の角丸の点線は曲がり目で破線がつながらない
- 寸法は `Timeline.astro` の frontmatter の定数 1 か所に置き、CSS には `define:vars` で、
  SVG のパスには計算で渡す。値を 2 か所に書くと曲線がノードから外れる

### 狭い画面では月の行を必ず 2 行にする

600px 未満では件数を月名の下に置き、600px 以上では 1 行にする。折り返しを成り行きに任せると
月の行の高さが変わり、曲線の終点が出来事のノードからずれる。曲線は 2 つの高さ用に 2 本描き、
メディアクエリで片方を表示する。狭い方の曲線は、件数の文字を避けて本線の脇を下りてから曲がる。

### Home は同じ部品を切り詰め、本線を途切れさせる

- `<Timeline digest={3} />`: 新しい月から順に、出来事の合計が 3 件に達した月まで出す
- 続きがあれば、本線は長さが短くなり間隔が広がる線分で薄れて消え、`>> MORE`（`/timeline/` へ）を置く
- 全件ページと同じ見た目にする。Home だけ別の形にすると、同じ Timeline だと読み取れない

### 書体とアイコン（ADR-0019 の範囲を広げる）

- 日付・件数・`>> MORE` は VT323（`--text-timeline` 22px、大文字、latin のみ）。22px の cap は 8.8px で、
  16px の Inter とほぼ同じ見た目の大きさになる。18px では数字が潰れる
- 種類は Work と同じタグ（`Tag.astro`）で示す
- 出来事の行の右端に、ソースのブランドアイコン（GitHub / Zenn）を 1 列に揃えて置く。
  月の行には付けない。すべて GitHub なので、同じアイコンが並ぶだけで情報が増えない

## Rationale

### 却下した案: 新しい順の 1 本のリスト（統計もエントリの 1 つ）

構造としては最も単純だが、統計が毎月 1 件ずつ増え、出来事が埋もれる。Home で統計を除外すると、
Home と全件ページで並びの規則が変わる。

## Consequences

- ADR-0017 の `<Timeline limit={6} />` は `<Timeline digest={3} />` に置き換わる。件数ではなく
  出来事の数で切るので、Home に出る月の数は月によって変わる
- ノードの丸は `border-radius` 0 の例外（形そのものが円である要素）に加わる
- Timeline の線は、内容の区切りの罫線ではなくグラフの要素として扱う。`--color-border` は使わない
- `.claude/rules/design.md` に、`--color-graph-mark`、`--text-timeline`、Timeline の要素の色、
  VT323 の範囲を追記する
- 出来事が増え 1 か月の分岐が長くなったときの見え方は、まだ検証していない
