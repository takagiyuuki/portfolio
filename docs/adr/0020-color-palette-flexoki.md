# ADR-0020: カラーパレットに Flexoki を採用する

Date: 2026-10-07
Status: Accepted

## Context

サイトの色はモノクロにリンクの青を 1 色加えただけの構成で、値は Tailwind の neutral / blue
から選んだ hex を `src/styles/global.css` に直接書いていた。

色を加えたいが、色を一から決めることは得意ではない。そこで、作者が設計した既存の
パレットを採用し、色の選定をパレットに任せる方針にした。

候補を比較する中で、パレットの性質によって次の問題が起きることが分かった。比率はすべて
WCAG 2 のコントラスト比で、Python で実測した。

- **1 つの色相に 1 色しかないパレットは、その色が AA を下回ったときに打つ手がない。**
  エディタ向けのパレットには、目の負担を減らすために accent のコントラストを抑えたものが
  多い。ライト版で AA（4.5:1）を満たす accent が 14 色中 2 色しかないパレットもあった。
  段階がなければ、パレットの外の色を足すしかない
- **muted と本文の明度差が小さいパレットでは、色だけで示している hover が見えなくなる。**
  nav と footer のリンクは、hover を「muted → 本文色」の色の変化だけで示している。
  現行の差（muted 対 本文の比）はライト 3.78 / ダーク 2.00 で、これが 1.2〜1.3 しかない
  パレットでは変化がほとんど分からない
- **コントラストを保証する設計のパレットは、数値は良いが見た目が現行と変わらない。**
  無彩色の灰色の階調に青を組み合わせると、現行の neutral + blue とほぼ同じ見え方になり、
  色を加えるという目的を果たさない

## Decision

### 選定基準

パレットは次の条件をすべて満たすものを選ぶ。

1. **各色相に明度の段階（スケール）がある**
2. **用途ごとの割り当て（本文・muted・リンクなどにどの色を使うか）を作者が公開している**
3. **公式の割り当てのまま、または同じ色相の段階をずらすだけで、本文・muted・accent が
   AA（4.5:1）を満たす**
4. **muted と本文の明度に差がある**（色の変化による hover が知覚できる）
5. **ライトとダークの両方の割り当てがある**

### Flexoki を採用する

[Flexoki](https://stephango.com/flexoki)（Steph Ango、MIT）を採用する。各色相に 50〜950 の
13 段階があり、base 色と accent 色の用途ごとの割り当てを作者が公開している。

### 割り当て

公式の割り当て（`bg` / `tx` / `tx-2` / `cy`）に従う。公式から外れるのはライトの accent
だけである。

| 用途 | 公式の名前 | ライト | ダーク |
| --- | --- | --- | --- |
| 背景 | `bg` | `paper` | `black` |
| 本文 | `tx` | `black` | `base-200` |
| muted | `tx-2` | `base-600` | `base-500` |
| accent | `cy` | **`cyan-700`** | `cyan-400` |
| 選択の背景 | — | `cyan-50` | `cyan-950` |

値と比率、要素ごとの色、将来追加する要素の色は `.claude/rules/design.md` に一覧がある。

- **accent は cyan にする。** 公式の割り当てで「Links, active states」に対応するのは `cy`
  であり、このサイトの accent はまさに本文リンクと nav の現在地の 2 つに使っている。
  `bl`（青）には UI 上の役割が割り当てられていない
- **ライトの accent は公式の `cyan-600` ではなく `cyan-700` にする。** `cyan-600` は
  対 paper 4.43 で AA を下回る。`cyan-700` は公式 README が「UI 向け」とする拡張パレット
  の色で、パレットの外には出ない
- **選択の背景は単色にする。** Flexoki のサイトは `rgba(187, 220, 206, 0.3)` を使っているが、
  色に `opacity` を使わない運用ルール（ADR-0021）に合わせて、見た目がほぼ同じ単色
  （背景との比 ライト 1.15 / ダーク 1.13、元サイトは 1.11）を拡張パレットから選ぶ

### primitive は使う色だけをコピーする

npm パッケージも CDN も使わず、使う色の hex だけを `src/styles/flexoki.css` にコピーする。
ファイルの先頭に出典、MIT ライセンス、`https://stephango.com/flexoki` へのリンクを書く
（README がクレジットとリンクの記載を求めているため）。

トークンの構造（primitive と semantic の 2 層、各ファイルの役割）は ADR-0021 で扱う。

## Rationale

### Flexoki が選定基準を満たすこと

8 色相すべてが、ライト（700 対 paper）とダーク（300 対 black）の両方で AA を満たす。
段階をずらすだけで AA を確保できる余地が、すべての色相にある。

| | red | orange | yellow | green | cyan | blue | purple | magenta |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| ライト 700 | 7.90 | 6.30 | 4.80 | 6.03 | 6.03 | 8.04 | 9.29 | 8.19 |
| ダーク 300 | 6.30 | 7.62 | 9.76 | 7.98 | 8.48 | 6.77 | 7.37 | 7.11 |

muted と本文の差はライト 3.75 / ダーク 2.31 で、現行（3.78 / 2.00）と同程度にある。
色の変化による hover は、パレットを変えた後も知覚できる。

### 却下した案: パレットの npm パッケージ / CDN を使う

npm で配布される CSS は全色・全形式（hex / rgb / hsl）を含み、未使用のカスタムプロパティを
削除する仕組みはこの構成にないため、使わない色もすべて配信される。パレットの値は変わらない
ので、バージョンを追う利点もない。CDN は描画を止める外部リクエストが増え、外部サービスへの
依存にもなる。

## Consequences

- **リンクは青ではなく cyan になる。** 本文リンクは常に下線を引いているので、リンクで
  あることは色ではなく下線で伝わる
- **ダークの本文のコントラストは現行より下がる**（15.72 → 11.98）。AAA（7:1）は引き続き
  満たす。ライトは 17.93 → 18.62 で上がる
- **accent と muted の明度差は小さい**（ライト 1.21 / ダーク 1.29）。nav の現在地と
  非アクティブ項目は、明るさではなく色相（cyan と暖かい灰色）と current マーカー（ADR-0019）
  で区別される。マーカーが色に頼らない手がかりになるので、WCAG 1.4.1 は満たす
- **公式の割り当てどうしでも、組み合わせによっては AA を満たさない。** たとえば muted を
  将来の `bg-2`（カードやコードブロックの背景）の上に置くと、ライトで 4.47 になる。
  新しい組み合わせを作るときは比率を確認する（ADR-0021 の運用ルール）
- **ライトで muted の文字を選択すると、選択中は 4.32 になる。** 選択は一時的な状態として
  許容する
- **`public/logo.svg` はこの変更の対象外。** 色（`#171717` と `white`）が SVG に直接
  書かれていてトークンに追従しないが、ロゴは作り直す予定のため別に扱う
- パレットを再び変えるときは、この ADR を置き換える新しい ADR を書き、上の選定基準で
  候補を評価する。トークンの構造（ADR-0021）は置き換えの対象にならない
